Priority Roadmap — What to Build Next

Critical (Week 1-2)

  • Wire up real DB logic for Inventory, Pharmacy, Lab, Radiology, Emergency, Nursing APIs
  • Implement Bed Allocation / Transfer / Discharge workflow
  • Build SignalR hub for real-time queue
  • Implement per-endpoint authorization (not just [Authorize])
  • Add FluentValidation to all controllers

High Priority (Week 3-4)

  • Billing engine: tax calculation, discounts, partial payments, refunds
  • Insurance module: companies, plans, claims workflow
  • OPD workflow: check-in → vitals → consult → billing
  • Prescription creation form with medicine search
  • Facility CRUD: buildings, wards, rooms, beds

Medium Priority (Month 2)

  • Global command palette (Ctrl+K)
  • Smart cross-module search
  • Report data generation + export
  • Audit logging middleware
  • Subscription / entitlement checking

Foundation (Month 2-3)

  • Background jobs (Hangfire)
  • Redis caching
  • SMS / Email / WhatsApp providers
  • File storage service
  • Health checks + structured logging
